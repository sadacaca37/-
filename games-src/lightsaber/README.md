# 광선검 결투 (펀펀 플레이)

졸라맨 제다이(파랑) vs 시스(빨강) 광선검 대결 게임. 그림·소리·움직임은 모두 코드로 만든다(이미지 파일 없음).

- **1인 플레이** — 컴퓨터와 대결 (쉬움 · 보통 · 어려움)
- **2인 플레이** — 한 컴퓨터에서 친구와 (1P: WASD + F G H, 2P: 방향키 + K L ;)
- **👥 2인 대결** — 각자 컴퓨터에서. 한 명이 방을 만들면 4자리 번호가 나오고, 친구가 그 번호로 들어간다.
  - 모아팡 Firebase `taja/duo/lightsaber/<번호>` 자리를 다른 펀펀 플레이 2인 대결 게임과 똑같이 쓴다.
  - 각자 쓰는 데이터는 방 안의 `st/<자기 uid>` 아래에만 둔다.
  - 처음 만날 때만 Firebase를 쓰고, 싸우는 동안은 두 컴퓨터가 직접(WebRTC) 주고받는다. 학교 망에서 직접 연결이 안 되면 6.5초 뒤 자동으로 Firebase 중계로 바뀐다.

## 고치는 법

`src/` 안의 파일을 고친 뒤

```
node games-src/lightsaber/build.mjs
```

을 실행하면 `public/games/lightsaber/index.html` 이 새로 만들어진다.

| 파일 | 내용 |
| --- | --- |
| core.js | 화면 크기·수학·애니메이션 도우미 |
| audio.js | 효과음과 음악 (WebAudio) |
| world.js | 무대(홀·벽·잔해) |
| fighter.js | 졸라맨 몸(관절·발 디딤) |
| fx.js | 불꽃·빛·화면 흔들림 |
| env.js | 배경과 인물·광선검 그리기 |
| netfb.js | 👥 2인 대결 연결 (Firebase + WebRTC) |
| game.js | 게임 규칙·조작·컴퓨터 AI·메뉴·화면 표시 |
