# data-seed (배포해도 학생 자료가 남게 하는 폴더)

배포하면 서버의 임시 저장 공간(data 폴더)이 비워집니다.
이 폴더에 넣어 둔 **seed-backup.json** 은 코드와 함께 올라가므로, 서버가 시작할 때
없는 학생과 학습 자료(포인트·연습 기록·별·퀘스트)를 자동으로 되살립니다.

## 쓰는 법
1. 사이트에서 마스터 관리실을 열고 **💾 전체 백업 받기** 를 누릅니다.
2. 받은 파일 이름을 **seed-backup.json** 으로 바꿔서 이 폴더(`data-seed/`)에 넣습니다.
3. 그대로 커밋해서 배포하면, 배포 뒤에도 학생 계정과 기록이 그대로 있습니다.

이미 서버에 있는 학생은 덮어쓰지 않고, 없는 것만 되살립니다.
